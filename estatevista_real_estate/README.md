# EstateVista — Real Estate Frontend

A responsive real-estate landing page built with **HTML, CSS and vanilla JavaScript**. No build tools or framework required.

## Run it
1. Extract the ZIP.
2. Open the `estatevista_real_estate` folder in VS Code.
3. Open `index.html` in a browser (recommended: VS Code Live Server).

## Easy edits
- **Property cards and details:** edit `js/properties.js`. Each object controls title, location, type, price, beds, baths, area, badge, image and description.
- **Colors and fonts:** edit the CSS variables at the top of `css/styles.css`.
- **Contact details:** search in `index.html` for `hello@estatevista.example` and `+923001234567`, then replace with real contact details.
- **Brand name:** replace `EstateVista` / `estatevista` in `index.html`.
- **Hero and about images:** replace the Unsplash image URLs in `index.html` and `css/properties.js`.

## Included interactions
- Responsive mobile navigation
- Property type filters
- Location and maximum-price search
- Save/favorite button UI
- Property details popup
- Contact form validation and email-app handoff

## Before publishing
This is a frontend demo. The contact form opens the visitor's email application; it does not store submissions. For production, connect a backend or a form service, replace demo contact details, use approved property photos and verify all property data. External Google Fonts and Unsplash images need an internet connection.
